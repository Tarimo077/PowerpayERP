Employee onboarding

1. Admin selects Add employee.

2. ERP generates an EMP-#### ID.

3. A three-day activation link is emailed.

4. Employee chooses their name and password.

5. Sign-in completes with a six-digit OTP.

Task lifecycle

Assigned→In progress→Submitted→Approved

Rejected work returns for correction; completed and approved tasks leave the active workload.

Timesheet lifecycle

Draft→Submitted→Approved

Employees add dated work entries and evidence. Managers review, comment, approve or reject. Approved records export to PDF or CSV.

Security model at a glance

Email + OTP

Password authentication is followed by a hashed, five-minute email code with five attempts.

Tenant isolation

Queries and relationships are restricted to the signed-in user’s organization.

Role checks

Views validate admin, manager and employee permissions before allowing changes.

Audit trail

Logins, creation, uploads, approvals and status changes record actor and timestamp.
